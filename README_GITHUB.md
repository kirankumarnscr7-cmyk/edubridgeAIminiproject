# Trading Data Cleaning Internship Task

## Files
- `trading_data_cleaning_internship.ipynb`: notebook for inspection, cleaning, feature engineering, visualization, time-based target/split, and exports.
- `trades_orderbook_STUDENT_dirty.csv`: instructor-provided synthetic input file.
- `requirements.txt`: required Python packages.

## Run locally
1. Install Python 3.10+ and Jupyter.
2. Run `pip install -r requirements.txt`.
3. Keep the input CSV beside the notebook.
4. Open the notebook and run all cells from top to bottom.

Outputs are written to `outputs/`. The raw CSV is not overwritten. Data is synthetic and for educational use only, not financial advice.
